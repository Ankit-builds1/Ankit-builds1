## Projects

**[Hierarchical Agentic Malware Classification](https://github.com/Ankit-builds1/hierarchical-agentic-malware-classification)**
Ensemble pipeline (Random Forest + XGBoost) that classifies malware from image-converted binaries using histogram and entropy-based features. Confidence thresholding cuts false positives by 18%, with 91% validation accuracy overall.
`Python` `Scikit-learn` `XGBoost`

**[Copy-Move Forgery Detection](https://github.com/Ankit-builds1/cmfd-efficientnetb4-vit-unet)**
Detects copy-paste image forgeries with a hybrid EfficientNetB4 + Vision Transformer + UNet architecture — CNN feature extraction combined with transformer attention to localize forged regions.
`Python` `PyTorch` `OpenCV`
